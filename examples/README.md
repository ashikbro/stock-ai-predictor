# Examples

This directory contains example scripts demonstrating how to use the Stock AI Predictor.

## Available Examples

### basic_usage.py

A complete walkthrough demonstrating:
- Fetching and preprocessing stock data
- Creating a trading environment
- Training a DQN agent
- Evaluating performance
- Comparing to buy-and-hold strategy

**Run it:**
```bash
python examples/basic_usage.py
```

## Creating Your Own Examples
