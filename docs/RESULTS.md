# Results and Benchmarks

## Metrics

- **MAE / RMSE / MAPE** for forecast quality
- **Cumulative Return** for strategy profitability
- **Sharpe Ratio** for risk-adjusted return
- **Max Drawdown** for downside risk

## Benchmarking Protocol

- Compare RL strategy vs buy-and-hold.
- Evaluate by market regime (bull, bear, sideways).
- Use out-of-sample windows only for headline numbers.

## Example Snapshot (Sample Data)

|---|---:|---:|---:|
